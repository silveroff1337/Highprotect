# Highprotect

Highprotect 1.0 — Discord-бот для защиты сервера от серии разрушительных действий. Он определяет исполнителя по журналу аудита, считает события за скользящий интервал и применяет санкции при превышении лимита.

## Что отслеживает бот

- Создание и удаление каналов, ролей и вебхуков.
- Изменение разрешений ролей и каналов.
- Кики и баны участников.

По умолчанию бот разрешает три действия за 10 секунд и реагирует на четвёртое. Счётчик общий для перечисленных действий одного исполнителя на одном сервере. Владелец сервера, сам бот и пользователи из `WHITELIST_USER_IDS` исключены. При срабатывании бот пытается выдать бан. Если бан недоступен, бот пытается снять доступные роли и отправляет отчёт в настроенный канал.

## Подключение к серверу

Для добавления бота нужно право **Управлять сервером**. Настройку канала отчётов выполняет администратор сервера.

1. Откройте [приглашение Highprotect](https://discord.com/oauth2/authorize?client_id=1570080149372932297&scope=bot&permissions=268455044), выберите сервер и подтвердите разрешения.
2. В настройках ролей поставьте роль Highprotect выше ролей участников, к которым бот должен применять санкции.
3. Напишите `.ping` в доступном боту текстовом канале. Highprotect ответит `Pong!`.
4. Создайте текстовый канал для отчётов, например `#anti-nuke`. Убедитесь, что бот может видеть канал, отправлять сообщения и встраивать ссылки. Затем выполните `.log set #anti-nuke`.

Бот использует **Просмотр журнала аудита**, **Управление ролями** и **Бан участников**. В канале отчётов нужны **Просмотр канала**, **Отправка сообщений** и **Встраивание ссылок**.

## Команды

| Команда | Назначение |
| --- | --- |
| `.ping` | Проверить, что бот отвечает. |
| `.log set #канал` | Сохранить канал отчётов для этого сервера. Доступно администраторам. |

Защита реагирует после появления записи в журнале аудита. Автоматическое восстановление удалённых объектов в версии 1.0 отсутствует.
